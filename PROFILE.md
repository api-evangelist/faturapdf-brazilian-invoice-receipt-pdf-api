# FaturaPDF — Brazilian Invoice & Receipt PDF API

HTTP API that converts a JSON payload into a Brazilian invoice (fatura) or receipt (recibo) PDF. Fiscal-native features include mod-11 checksum-validated CPF/CNPJ, BRL formatting, Portuguese amount spelling, and optional PIX QR rendering. Not an NF-e/NFS-e fiscal issuer. Metered and billed via RapidAPI with a free tier.
